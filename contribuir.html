Contribuir

Adicione ou corrija dados de salas.

O foco inicial é catalogar redes, cinemas e salas com informações técnicas úteis para comparação. Dados incompletos são aceitos quando ficam marcados como A confirmar ou null.

Abrir issue no GitHub Enviar por email

Fluxo

  1. Escolha uma rede, cinema ou sala para adicionar ou corrigir.
  2. Procure uma fonte: site oficial, imprensa, foto, visita ou relato.
  3. Abra uma issue usando o modelo de novo dado ou correção.
  4. Preencha apenas o que souber; o restante pode ficar como A confirmar.

Formas de enviar

GitHub Issues Melhor caminho para novos cinemas, novas salas e correções. Twitter Envie uma mensagem para @publi0. Email Envie dados, links, fotos ou dúvidas para felipe@publio.dev.

O que coletar

Rede

Nome da rede ou operador independente.

Cinema

Nome, cidade, bairro e endereço.

Sala

Nome da sala, formato comercial, capacidade e tecnologias.

Projeção

Tecnologia, resolução, marca, modelo e observações.

Tela

Tipo, proporção, largura, altura, área ou diagonal.

Som

Formato, canais, quantidade de caixas, potência e notas.

Padronização dos dados

O campo format descreve o que a sala tecnicamente oferece, não o nome comercial da rede. Nomes de marketing — XD, XPLUS, Platinum, Macro XE, Laser Lounge, Bradesco Prime etc. — vão em notes ou na fonte, nunca em format. Termos como IMAX e Dolby Atmos são aceitos porque têm especificações públicas e auditáveis independente de qualquer rede.

Como preencher uma issue

Novo cinema ou sala

Use quando a rede, o cinema ou a sala ainda não aparece no catálogo.

  • Informe rede, cinema, cidade e sala.
  • Descreva o formato técnico: tela grande, poltronas reclináveis, IMAX, 4DX, Dolby Atmos etc.
  • Preencha projeção, tela e som com o máximo de detalhe disponível.
  • Cole links ou descreva a fonte usada.

Correção de dados

Use quando uma sala já existe, mas algum campo está incorreto ou incompleto.

  • Identifique rede, cinema e sala afetados.
  • Explique o que está errado.
  • Informe a versão correta.
  • Inclua uma fonte para facilitar a revisão.

Regras práticas

  • Use null para número desconhecido.
  • Use A confirmar para texto desconhecido.
  • Não invente potência, resolução, tamanho de tela ou canais.
  • Prefira nomes oficiais de rede, cinema e sala.
  • Inclua uma fonte ou uma observação explicando de onde veio o dado.
