Contribuir

Adicione ou corrija dados de salas.

O foco inicial é catalogar redes, cinemas e salas com informações técnicas úteis para comparação. Dados incompletos são aceitos quando ficam marcados como A confirmar ou null.

Abrir issue no GitHub Enviar por email

Fluxo

  1. Escolha uma rede, cinema ou sala para adicionar ou corrigir.
  2. Procure uma fonte: site oficial, imprensa, foto, visita ou relato.
  3. Abra uma issue usando o modelo de novo dado ou correção.
  4. Preencha apenas o que souber; o restante pode ficar como A confirmar.

Formas de enviar

GitHub Issues Melhor caminho para novos cinemas, novas salas e correções. Twitter Envie uma mensagem para @publi0. Email Envie dados, links, fotos ou dúvidas para felipe@publio.dev.

O que coletar

Rede

Nome da rede ou operador independente.

Cinema

Nome, cidade, bairro e endereço.

Sala

Nome, capacidade e sistemas técnicos identificáveis.

Projeção

Tecnologia, resolução, marca, modelo e observações.

Tela

Tipo, proporção, largura, altura, área ou diagonal.

Som

Formato, canais, quantidade de caixas, potência e notas.

Padronização dos dados

O catálogo não usa uma categoria genérica de “formato”. A sala é descrita pelos dados verificáveis de projeção, resolução, tela e som. technologies é uma lista fechada: IMAX, Macro XE, XD, Cinépic e UCI XPLUS são sistemas; 3D e 4DX são experiências. “Convencional”, VIP e tipos de poltrona não são classificações técnicas.

Onde registrar cada especificação

Campo O que registrar
projection Película ou tela direta, marca, modelo, resolução, fonte de luz e configuração
screen Tecnologia, superfície, geometria, proporção e dimensões verificáveis
sound Formato, layout, processamento, canais, streams, caixas e potência
technologies IMAX, Macro XE, XD, Cinépic e UCI XPLUS como sistemas; 3D e 4DX como experiências, sem repetições
notes Nomes comerciais ou contexto que não comprovem uma especificação técnica

Grande Formato não é uma tecnologia válida porque não define uma especificação. Registre projeção, resolução, dimensões da tela e som nos campos próprios. Digital isolado ainda é insuficiente. Em áudio, use Multicanal quando a fonte confirmar reprodução por canais sem informar uma tecnologia proprietária, e registre o layout separadamente.

IMAX, Macro XE, XD, Cinépic e UCI XPLUS são sistemas. Laser e Xenon ficam em light_source; Película 70 mm fica em projection.technology.

4DX é uma experiência com efeitos físicos. Use type: "experience"; projeção e som permanecem nos campos próprios.

Samsung Onyx fica como tela direta, marca e modelo em projection. Laser e Xenon ficam apenas em light_source. Em áudio, formato, layout e processamento são campos diferentes. Fontes vazias não são aceitas.

Como preencher uma issue

Novo cinema ou sala

Use quando a rede, o cinema ou a sala ainda não aparece no catálogo.

  • Informe rede, cinema, cidade e sala.
  • Classifique IMAX, Macro XE, XD, Cinépic e UCI XPLUS como sistemas; 3D e 4DX como experiência; Dolby Atmos como som; Onyx como imagem.
  • Preencha projeção, tela e som com o máximo de detalhe disponível.
  • Cole links ou descreva a fonte usada.

Correção de dados

Use quando uma sala já existe, mas algum campo está incorreto ou incompleto.

  • Identifique rede, cinema e sala afetados.
  • Explique o que está errado.
  • Informe a versão correta.
  • Inclua uma fonte para facilitar a revisão.

Regras práticas

  • Use null para número desconhecido.
  • Use A confirmar para texto desconhecido.
  • Não invente potência, resolução, tamanho de tela ou canais.
  • Prefira nomes oficiais de rede, cinema e sala.
  • Inclua uma fonte ou uma observação explicando de onde veio o dado.
